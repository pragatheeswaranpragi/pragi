# Pragatheeswaran K — portfolio

A personal front-end engineering portfolio built with Next.js and React.

```sh
npm ci
npm run dev
```

Use Node.js 20.9 or later. Run `npm run build` to validate production output.

Content: `lib/content.js`. Homepage: `pages/index.js`. Design: `styles/portfolio.css`.

See `PORTFOLIO-UPDATE.md` for SEO changes, verification limits, portable previews,
and deployment instructions for the existing portfolio project.
