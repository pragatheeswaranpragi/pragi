## Run

Requires Node.js 20.9 or later.

```sh
npm ci
npm run dev
```

Production check:

```sh
npm run build
npm run start
```

This project now uses Next.js 15.5.27 and React 18.3.1. Use npm and the supplied
package-lock.json. The old yarn.lock was removed to avoid conflicting installers.

## Preview

Open preview/index.html after extracting this archive. It shows the production
HTML and CSS with navigation, the package playground, project disclosure and copy behavior.
Open preview/responsive-review.html for 390px mobile and 768px tablet frames.
These are portable review files; they are not a replacement for the Next.js app.
The preview folder is excluded from Vercel uploads.

## Deploy to the existing project

1. Make a backup or use a feature branch in pragatheeswaranpragi/pragi.
2. Apply the contents of this folder to the repository, including removal of the
   old pages/component directory and yarn.lock. Leave existing Git metadata intact.
3. Push the feature branch and verify the preview generated by the existing
   Vercel Git integration. Confirm the project owns pragatheeswaran.vercel.app.
4. Verify navigation, résumé downloads, the mobile menu and the page at narrow widths.
5. Merge to the project's production branch after reviewing the preview.

The connected Vercel account available during this work did not provide access to
the portfolio's workspace. This update has not been pushed or deployed.
